# Chota Ops dashboard

Small Next.js page for the ops side: live bookings over the WebSocket, truck status, feature flags with rollout sliders, experiment results and slot capacity.

```bash
cp .env.example .env.local   # points at the backend on :4000
npm install
npm run dev -- -p 3001       # http://localhost:3001, sign in with +254700000001
```
